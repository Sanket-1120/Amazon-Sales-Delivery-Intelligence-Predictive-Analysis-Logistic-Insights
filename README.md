Analyze Amazon sales data to predict courier delivery status using machine learning. Includes data cleaning, visualizations, and four classification models (Logistic Regression, Decision Tree, Random Forest, KNN) to uncover insights and improve logistics performance.
# 📦 Amazon Sales Delivery Intelligence

This project analyzes Amazon sales and courier delivery data to predict delivery outcomes and gain business insights. It uses machine learning models and visual analytics to identify shipping delays and suggest improvements in logistics and fulfillment.

## 🚀 What’s Inside
- Data cleaning and preprocessing
- Exploratory visualizations
- Four machine learning models:
  - Logistic Regression
  - Decision Tree
  - Random Forest
  - K-Nearest Neighbors
- Model comparison and evaluation
- Final conclusions and business recommendations

## 🎯 Goal
Predict courier status (Delivered, Not Delivered, etc.) based on order details, and help Amazon make informed decisions to improve delivery success and customer satisfaction.

## 🛠️ Tools & Tech
- Python (Pandas, NumPy, Scikit-learn)
- Jupyter Notebook
- Matplotlib, Seaborn

## 📈 Business Impact
- Early detection of delivery issues
- Regional logistics optimization
- Enhanced customer experience
